## Description

Escape the ball 2.0 is the next attempt and interation of the 3rd variable prototype. in this version, i build on top of my original code, clean it up and add the death and reset features to make it a 'complete' playable game. the goal is to evade the ball as long as possible and get the highest timer score possible. the ball slowly speeds up over time which makes it more difficult.
